# Hilary Nwankwo, portfolio site

Static site (HTML, CSS, a little JS). No build step.

- Design: "Blue Professional" system from [beautiful-html-templates](https://github.com/zarazhangrui/beautiful-html-templates) (MIT), adapted from slides to a responsive page. Fonts: Space Grotesk and Inter.
- Content source: the master CV in the Career workspace. Update the CV first, then this site.
- Preview locally: open `index.html`, or run `python -m http.server` in this folder.

## Hosting (GitHub Pages)
Repo name `heelaree.github.io`, branch `main`, Pages source "Deploy from a branch" / root. Served at https://heelaree.github.io/.
